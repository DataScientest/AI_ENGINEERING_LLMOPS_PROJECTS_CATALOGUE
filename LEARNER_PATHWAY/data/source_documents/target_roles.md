## Data Analyst

### Definition
Analyzes data to extract insights and produce reports. Uses SQL, Excel, and visualization tools.

### Required skills

- Advanced SQL
- Visualization tools (Tableau, PowerBI)
- Basic statistics
- Advanced Excel

### Desirable skills

- Python basics
- Communicating results

### SkillPath recommended trainings

| Training | Duration | Prerequisites |
|----------|----------|---------------|
| Python for Data | 24h | None |
| Advanced SQL and Optimization | 16h | SQL basics |
| Data Visualization and Storytelling | 16h | None |

## Data Scientist

### Definition
Develops machine learning models to solve business problems. Combines stats, ML and communication.

### Required skills

- Advanced Python (pandas, numpy)
- Advanced statistics
- Machine Learning (sklearn)
- Feature engineering
- Model evaluation

### Desirable skills

- Deep Learning (PyTorch)
- NLP
- Advanced visualization

## LLM Engineer

### Definition
Deploys RAG and LLM systems in production. Manages prompt versioning, evaluation and monitoring.

### Required skills

- RAG (LangChain, LlamaIndex)
- Vector stores (Qdrant, pgvector)
- Advanced prompt engineering
- LLMOps (MLflow, prompt versioning)
- Evaluation (Ragas, DeepEval)

### Desirable skills

- Fine-tuning (LoRA)
- Function calling
- Ollama/vLLM deployment

### SkillPath recommended trainings

| Training | Duration | Prerequisites |
|----------|----------|---------------|
| LLM and RAG Fundamentals | 24h | Python |
| LLMOps — Deployment and Monitoring | 32h | LLM concepts, Docker |

## Pathway advice

### To get started in Data

1. Start with Python + SQL
2. Add statistics
3. Specialize (DS, DE, or MLOps)

### To specialize in ML/AI

1. Have a solid foundation in Python and stats
2. Choose your path: classical ML or Deep Learning/LLM
3. Get into production quickly (MLOps)

### To move into LLM Engineer

1. Master the ML fundamentals
2. Learn RAG and vector stores
3. Work on prompt engineering
4. Set up evaluation and monitoring
