# Job Profile — LLM Engineer

## Definition

The **LLM Engineer** is responsible for designing, deploying and maintaining production systems based on Large Language Models. They combine MLOps skills with expertise in prompt engineering and Retrieval-Augmented Generation (RAG).

## Differences from neighboring jobs

| Job | Main focus |
|-----|------------|
| Prompt Engineer | Writing prompts, prompting optimization |
| ML Researcher | Research on model architectures |
| **LLM Engineer** | RAG/LLM deployment in production, LLMOps |

## Key responsibilities

- Design and implement high-performing RAG architectures
- Manage the versioning of prompts and configurations
- Deploy and monitor LLM models in production
- Set up evaluation pipelines (Ragas, DeepEval)
- Detect and manage response drift

## Technical skills

### Required skills

| Skill | Expected level | Tools/Technologies |
|-------|----------------|--------------------|
| RAG (Chunking, Embeddings) | Advanced | LangChain, LlamaIndex |
| Vector Stores | Intermediate | Qdrant, pgvector, Pinecone |
| Prompt Engineering | Advanced | Advanced techniques, Few-shot |
| LLMOps | Intermediate | MLflow, prompt versioning |
| Evaluation | Intermediate | Ragas, DeepEval |
| Deployment | Intermediate | Ollama, vLLM |

### Appreciated skills

- Fine-tuning (LoRA, QLoRA)
- Function calling / agents
- Specific metrics (hallucination, groundedness)

## Typical path to the job

### Profiles that move into LLM Engineering

- **ML Engineers** with production experience
- **NLP Researchers** who want to move into production
- **Python Software Engineers** with ML/LLM knowledge

### Training path (12-18 months)

| Step | Training | Duration |
|------|----------|----------|
| 1 | LLM and RAG Fundamentals | 24h |
| 2 | LLMOps — Deployment and Monitoring | 32h |

**Total**: ~56 hours

Prerequisites: advanced Python, basic ML knowledge, notions of Docker.

## Possible career progression

- **ML Platform Engineer**: Design of an internal ML/LLM platform
- **AI Solutions Architect**: Architecture of complete AI solutions
- **Research Engineer**: Focus on model optimization

- Explosive demand with the rise of LLMs (GPT, Claude, Mistral, Llama)
- Companies want to internalize their LLM use cases
- RAG + LLMOps is the most in-demand skill
- Significant growth expected with generative AI
