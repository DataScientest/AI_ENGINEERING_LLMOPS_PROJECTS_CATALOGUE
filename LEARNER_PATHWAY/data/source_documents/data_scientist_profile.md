# Job Profile — Data Scientist

## Definition

The **Data Scientist** is responsible for data analysis, statistical modeling and the development of machine learning models to solve business problems. They combine technical skills (stats, ML, Python) with business skills (understanding the problem, communication).

## Key responsibilities

- Analyze data to extract insights
- Develop and evaluate ML models
- Communicate results to stakeholders
- Work with business and technical teams

## Technical skills

### Required skills

| Skill | Expected level | Tools/Technologies |
|-------|----------------|--------------------|
| Statistics | Advanced | hypothesis tests, distributions |
| Python | Advanced | pandas, numpy, scikit-learn |
| ML | Intermediate | sklearn, classical models |
| Feature Engineering | Intermediate | feature selection, feature creation |
| Model evaluation | Intermediate | metrics, cross-validation |

### Appreciated skills

- Deep Learning (PyTorch, TensorFlow)
- NLP (spaCy, Hugging Face)
- Visualization (matplotlib, seaborn)
- MLflow (basics)

## Typical path to the job

### Ideal hiring profile

- Degree in stats/math/computer science (Master's level)
- Experience in data analysis
- Familiarity with Python tools

### Training path (12-18 months)

| Step | Training | Duration |
|------|----------|----------|
| 1 | Python for Data | 24h |
| 2 | Statistics for Data Science | 20h |
| 3 | Introduction to Machine Learning | 32h |
| 4 | Feature Engineering and Selection | 16h |

**Total**: ~92 hours

## Possible career progression

- **Senior Data Scientist**: In-depth technical expertise
- **Data Scientist Lead**: Team leadership
- **Machine Learning Engineer**: Move into production
- **Data Analyst**: Return to pure analysis

## Median salary (France, 2024)

| Experience | Median salary |
|------------|---------------|
| Junior (0-2 years) | 40-50 k€ |
| Intermediate (2-5 years) | 50-70 k€ |
| Senior (5+ years) | 70-95 k€ |

## Current market

- Mature market that still has strong demand
- Upskilling toward Deep Learning and LLMs
- Strong competition for junior profiles
- Senior profiles with a full stack are rare
