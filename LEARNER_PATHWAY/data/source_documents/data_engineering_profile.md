# Job Profile — Data Engineer

## Definition

The **Data Engineer** is responsible for designing, building and maintaining the infrastructure that moves and stores data at scale. They are the bridge between raw data and analytical or ML use cases.

## Key responsibilities

- Design and maintain robust, scalable data pipelines
- Ensure data quality and integrity
- Optimize query and processing performance
- Work with Data Scientists to provide the data they need

## Technical skills

### Required skills

| Skill | Expected level | Tools/Technologies |
|-------|----------------|--------------------|
| Python | Advanced | pandas, PySpark, scripts |
| SQL | Advanced | PostgreSQL, BigQuery, Snowflake |
| Orchestration | Intermediate | Apache Airflow, Dagster |
| Storage | Intermediate | S3, GCS, Delta Lake |
| Containers | Intermediate | Docker, Docker Compose |

### Appreciated skills

- Spark / PySpark for distributed processing
- Kafka or Pulsar for streaming
- dbt for SQL transformation
- Terraform for IaC

## Typical path to the job

### Ideal hiring profile

- Python developer with 2-3 years of experience
- Knowledge of SQL and databases
- Basic cloud knowledge (AWS, GCP or Azure)

### Training path (18-24 months)

| Step | Training | Duration |
|------|----------|----------|
| 1 | Python for Data | 24h |
| 2 | Advanced SQL and Optimization | 16h |
| 3 | Data Engineering with Apache Spark | 40h |
| 4 | Airflow and Orchestration | 16h |
| 5 | DevOps Fundamentals for Data | 16h |

**Total**: ~112 hours

## Possible career progression

- **Data Architect**: Design of the overall data architecture
- **Analytics Engineer**: SQL transformation with dbt
- **Platform Engineer**: Internal data infrastructure

## Median salary (France, 2024)

| Experience | Median salary |
|------------|---------------|
| Junior (0-2 years) | 45-55 k€ |
| Intermediate (2-5 years) | 55-75 k€ |
| Senior (5+ years) | 75-95 k€ |

## Current market

- Strong demand in the French and European markets
- Companies are looking for profiles able to handle large volumes
- Cloud mastery (AWS/GCP) is a major asset
