# Job Profile — MLOps Engineer

## Definition

The **MLOps Engineer** (or production ML Engineer) is responsible for deploying and maintaining machine learning models in production. They are the bridge between Data Science and the production system, ensuring that models run reliably and perform well.

## Key responsibilities

- Deploy and monitor ML models in production
- Set up automated ML pipelines (CI/CD for ML)
- Manage the model lifecycle (model registry, versioning)
- Detect and manage drift (performance degradation)

## Technical skills

### Required skills

| Skill | Expected level | Tools/Technologies |
|-------|----------------|--------------------|
| Docker | Advanced | Dockerfile, Docker Compose |
| CI/CD | Intermediate | GitLab CI, GitHub Actions |
| Experiment tracking | Intermediate | MLflow, DVC |
| Monitoring | Intermediate | Prometheus, Grafana, Evidently |
| Python | Advanced | Scripts, FastAPI |

### Appreciated skills

- Kubernetes for orchestration
- Kubeflow or BentoML for serving
- Feature store (Feast, Tecton)
- A/B testing for models

## Typical path to the job

### Profiles that move into MLOps

- **ML Engineers** who want to move into production
- **DevOps** engineers who want to specialize in ML
- **Data Engineers** with ML experience

### Training path (12-18 months)

| Step | Training | Duration |
|------|----------|----------|
| 1 | DevOps Fundamentals for Data | 16h |
| 2 | MLOps Fundamentals | 24h |
| 3 | Advanced MLOps — Production | 32h |

**Total**: ~72 hours

Prerequisites: skills in Python, SQL, and notions of ML.

## Possible career progression

- **ML Platform Engineer**: Design of the internal ML platform
- **ML Reliability Engineer**: Focus on the reliability of ML systems
- **Senior ML Engineer**: Technical leadership of an ML team
