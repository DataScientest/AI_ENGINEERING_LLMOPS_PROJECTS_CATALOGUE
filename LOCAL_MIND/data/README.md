# Exploration resources — LocalMind

This folder gathers fictional exploration resources for the LocalMind project.

## Documents to explore

The `source_documents/` folder contains documents of various sizes:

- `product_meeting_minutes.txt` — short (one page);
- `remote_work_policy.md` — medium;
- `lumen_foundation_2025_activity_report.md` — long.

You can complement them with your own test documents, including PDFs if you want to explore reading them.

## Example instructions

The `example_prompts/` folder offers two variants of summarization instructions (`prompt_v1.txt` and `prompt_v2.txt`). They contain the `{document}` placeholder to be substituted.

## Evaluation cases

The `evaluation_sets/eval.csv` file associates a reference summary with each document. Its columns are `eval_id`, `document` and `reference_summary`.

All provided files are fictional examples.
